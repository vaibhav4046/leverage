# Supademo: the interactive demo

Eight stills cut from the recordings behind the demo film, in the order the
interactive demo walks through them, with the hotspot text for each step. Every
number in the text is on the site or in a recorded mission; nothing here is a
mock-up.

## Upload

1. In a browser signed in to the Supademo account the MCP connector is bound to,
   open a fresh upload link (ask the assistant for one; it expires after an hour).
2. Drop the eight `*.jpg` files in this folder, in name order.
3. Optionally add `public/motion/demo.mp4` (the 2:22 film) as the final step.
4. Tell the assistant the upload is done; it assembles the demo from the upload
   job, sets the hotspot text below, and publishes.
