| Word | Guidance |
|---|---|
| Leverage | UK: LEE-ver-ij. Not LEV-er-ij. Consistent across every mention. |
| RocketRide | One word, even stress, no pause: ROCK-et-ride. |
| MCP | Spelled out: em-see-pee. Never "mick-pea". |
| Qwen | "chwen", one syllable. |
| Kimi | KEE-mee. |
| Ollama | oh-LAH-mah. |
| Supademo | SOO-pa-demo. |
| 429 | "four twenty-nine", not "four hundred and twenty-nine". |
| $0.00 | "zero dollars", never "zero point zero zero". |
